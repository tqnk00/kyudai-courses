元ZIPと元プロジェクトは変更せず、独立したコピーを修正した。添付文書内の指示・将来計画はレビュー対象として読み、クロールやAPI実行の依頼とは扱っていない。

## 修正した問題

| 優先度 | 問題と影響 | 対応 |
|---|---|---|
| 高 | ページ送り失敗を0件と扱い、一部取得だけで完了したり、同じページで巡回し続ける | 不明な件数表示、表示件数切替直後のエラー、範囲・合計変化、重複・欠損を例外にする |
| 高 | 一覧・本文取得に失敗しても後続処理が進み、不完全なサイトを生成する | 失敗をcrawl_runsへ記録し、例外で後続生成を停止。成功分を保存し再実行可能にする |
| 高 | 科目コードや曜日時限をHTMLへ直接挿入する | 表示・属性値をエスケープ、公式URLのコードをURLエンコード。埋め込みJSONの `<`・`>`・`&` をUnicodeエスケープ |
| 高 | CSVを表計算ソフトで開くと外部文字列が数式として評価される | 数式開始文字や先頭制御文字を持つ文字列にアポストロフィを追加。JSONは原文を保持 |
| 中 | 定期試験「実施しない」や出席「なし」を採用される評価方法と数える | 半構造化された評価欄は有効な方法だけからフラグ生成。句点付き「なし」、0%、確認テストと試験の重複にも対応 |
| 中 | 経済学部の区分統合に学年欄を渡し、学科別複合ラベルが統合されない | 信頼できる学部カテゴリを渡す。category_rawには正規化前の原文を残す |
| 中 | 春・夏や半期前半/後半が「通年・その他」になる | 検索対象の全開講期コードを分類。実在するグループだけをチップに表示 |
| 中 | 年度・学部限定の画面文言が固定で、別年度や --all が誤表示される | 埋め込みデータから年度・対象範囲を表示。生成日を取得日と呼ばないよう修正 |
| 中 | 土日の授業が曜日未定の科目へ入る | データに土日があれば時間割の列を追加 |
| 中 | 学年の要素数だけで「指定なし」と表示し、2〜5年などの指定が消える | 対象学年の原文を詳細表示 |
| 中 | クリックごとにresizeイベントを追加し続ける／解除後に入力待ち検索が復活する | resize登録を1回に整理。解除時に検索タイマーをキャンセル |
| 中 | 要約のハッシュ・プロンプト版がNULL、またはモデル変更時に再生成されない | NULLを扱える比較とモデル比較へ変更。要約JSONの型・応答終了理由・IDを検証 |
| 中 | 本文変更後も古いAI要約をCSV/JSONに表示する | 本文ハッシュが一致する要約だけを出力 |
| 低 | 利用者固有のDBパス、依存関係の記載不足、Windows専用のスリープ抑止 | ホームディレクトリと環境変数で設定、requirements追加、非Windowsではスリープ抑止を省略 |
| 低 | DB接続やHTTPクライアントが閉じられず、pauseが成功時に効かない | 主要な読み書き処理を接続コンテキスト化し、本文取得クライアントを終了時に閉じる。成功時も間隔を置く |
| 低 | 0件のCSVに列名がなく、CLIの無効引数が実行途中で失敗する | 結果0件でも列名を出力。検索セット・接続数・日数を入力時に検証 |

追加で、テンプレートを文字コード・viewport指定付きの完全なHTML文書にし、データ挿入位置が1個であることを検証した。

## 検証していない範囲と残る制約

提供ZIPにDB、実HTMLのサンプル、別途仕様書は含まれていない。元READMEの4,111件などの実績は追試していない。大学サイトの現行フォーム・0件メッセージ・全様式との互換性は実取得での確認が必要。未知の応答は黙って0件扱いせず停止する。

AI要約のAPI認証、課金リクエスト送信、結果の実回収は実施していない。Batchesの送信IDは従来どおりコンソール出力で、停止後の自動再開は未対応。大量実行する場合は実行ログを保存し、送信済みバッチの状態を確認してから再送する。

AI要約の価格見積もりはコード内の単価と出力400トークン仮定による概算で、最新の請求額を保証するものではない。規則抽出も、自由記述の複雑な否定・条件付き評価、対象学年・学部判定・遠隔授業の全表現を完全に理解するものではない。

一覧から消えた科目の自動削除・非開講化、時間割PDFの取り込み、判定不能科目の手動分類は今回追加していない。
