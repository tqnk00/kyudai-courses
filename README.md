# 九大 授業さがし（2026年度）

九州大学のシラバスを、時間割のコマから探せるようにした1枚のWebページです。
`index.html` と `details-2026/` を置くだけで動きます。サーバー側の処理もデータベースも要りません。

**公開URL**: https://tqnk00.github.io/kyudai-courses/

## できること

- 学部・学科（コース・分野・専攻）・科目区分・学年・キャンパス・開講期での絞り込み（最初は今の学期＋通年を選んだ状態で開く）。
  学科は、工・理・農・芸工・薬・医学部保健学科・文（専門分野）で選べる
- 科目名・教員名・キーワードでの検索（全角/半角と空白区切りのAND対応）
- 時間割のコマを押すと、そのコマの科目一覧
- 科目名を押すと、授業概要・授業計画・成績評価の内訳・公式シラバスへのリンク
- ★でお気に入り登録。お気に入りだけの時間割に切り替え可能
- 「お気に入りを時間割化する」で、自分の時間割ページへ（コマの追加・削除、単位数の合計、
  教室、シラバスへのリンク。時間割アプリのような画面）。前期／後期を切り替えて表示。
  同じコマに秋学期と冬学期（春学期と夏学期）の科目を1つずつ入れると、上下半分ずつに並べて出す
- 時間割ページの「共有・ほかの端末で開く」で、時間割をリンクとQRコードにして渡せる。
  開いた側は中身を見てから「入れ替える／追加する／取り込まない」を選ぶ（勝手に上書きしない）。
  PC→スマホはQRコード、スマホ→PCはリンクを自分宛てに送る。サーバーを持たないので自動同期はしない
- 時間割ページの「カレンダーに入れる」で、表示中の学期の時間割をカレンダー用ファイル（.ics）に書き出せる。
  Google カレンダーはPCの「設定 → インポート」で取り込む。日付は公式の授業日程どおりで、祝日・九大祭・
  冬季休業は入らず、振替授業日（木曜に月曜の授業など）は入る。学部ごとの日程の違い（工・法・経済・農）も反映
- 絞り込んだ状態がURLに残るので、その条件のままリンクで共有できる
- 開いた詳細は、絞り込みを変えても開いたまま
- 「文字を大きく」で一覧の科目名と詳細の本文を拡大（URLにも残る）
- 「要事前申請だけ」で、基幹教育の事前申請が要る科目だけに絞れる（ほかの条件と組み合わせ可）
- 教室を表示（全体の約半分）。文学部はシラバスから、基幹教育は開講科目一覧（B表）から、
  ほかの学部は各学部が公開している時間割表から取得
- 基幹教育の**事前申請**（約330件）を一覧のタグと詳細に表示。○はMoodleでの事前申請が必要、
  ●はCampusmate‑Jでの履修登録が申請を兼ねる。※は教員による抽選。2026年度入学者用と2025年度入学者用の
  どちらのB表に書かれた印かも示す
- 時間割表には載っているのにシラバスが無い科目を、ページ下部に一覧で掲載
- 「学部を色分け」で一覧の学部ごとに色を付ける（既定は色分けなし）
- 縦画面でも、1〜2件しかないコマは科目名まで表示
- 同じコマに複数入れたときは、重なっている科目名を全部並べて注意の色で表示
- 掲載情報がすべて九州大学の公開資料からの引用であることと、出典の一覧をページ上部・下部に明示
- スマホ表示対応（入力欄で画面が勝手に拡大しない文字サイズ、指で押せるボタンの大きさ）。ダークモード対応

## データについて

- 出典: 九州大学シラバス（Campusmate）／文学部シラバス・時間割（文学部独自サイト）
- 教室・事前申請の出典: 基幹教育院の開講科目一覧（B表）、教育・法・経済・理・工・農・芸工・共創の各学部が公開している時間割表（PDF。前期・後期）
- 収録: 2026年度の**学部科目 約5,800件**（うち文学部 約500件。正確な件数はページ上部に表示。2026-10-01 時点）
- 対象の開講期: 前期・春学期・夏学期・後期・秋学期・冬学期・通年・集中の全開講期
- 取得日: ページ上部の「サイト生成日」を参照（`update.bat` で取り直した日）

**取得時点のスナップショットです。** 開講の有無・教室・日程・成績評価は変更されることがあります。
履修登録の判断は必ず公式のシラバスで確認してください。各科目の詳細から公式ページへ移動できます。

科目名・成績評価・授業計画は自動抽出しているため、原文と食い違う場合があります。
とくに成績評価の割合は、出席条件など配点でない数値を除く処理を入れていますが、完全ではありません。

## 更新のしかた

**`update.bat` をダブルクリックするだけ**です（DBのあるPCで）。次の順に進み、最後に公開するかを聞きます。

1. Campusmate の一覧を取り直し、新しく増えた科目の本文を取る（数分〜）
2. 文学部のシラバスを取り直す（約9分）
3. 各学部の時間割表PDFを取り直し、教室と事前申請を作り直す
4. ページを組み立てて、このフォルダの `index.html` と `details-2026/` を入れ替える
5. テストを走らせる。失敗したら公開しない
6. 変更があれば「公開しますか？」と聞く。`y` で commit と push まで行う

コマンドで動かすなら `cd src` して `py run.py update`。`--skip-lit` で文学部を省略、`--yes` で確認なしに公開。
学部が時間割PDFのファイル名を変えていると 3 で「取れなかったPDF」と出るので、`src/timetable_pdfs.py` のURLを直す。

## 技術メモ

- 一覧・検索・時間割に使うデータはページ内にJSONとして埋め込み（2.3MB、転送は約0.4MB）
- 授業の概要・授業計画・成績評価などは `details-2026/` に64分割して置き、詳細を開いたときに
  その科目の入った1ファイル（転送は約60KB）だけを読む。分割先は科目コードのハッシュ（FNV-1a）で決まる
- `index.html` をファイルとして直接開くと、ブラウザの制限で分割ファイルを読めない。その場合、
  詳細には読めなかった旨と公式シラバスへのリンクが出る（検索と時間割はそのまま使える）
- 外部依存はGoogle Fonts、GoatCounter（訪問数の計測）、QRコード生成（qrcode-generator。共有を開いたときだけ
  jsdelivr から読み込み、integrity で中身を固定）。どれも読み込めなくてもページは動く
- お気に入りは `localStorage` に保存。端末のブラウザごとで、サーバーには送りません

## このリポジトリの構成

```
index.html   配布しているページそのもの（GitHub Pages がこれを配信）
details-2026/  詳細を開いたときに読む分割ファイル（index.html と一緒に置く）
update.bat   データ更新用。ダブルクリックで取り直しから公開の確認まで進む
src/         作るためのコード一式（読む順番と各ファイルの役割は src/README.md）
docs/history/ 過去のレビューと設計の記録
src/data/    Campusmateに無い情報（文学部のシラバス、各学部の教室、事前申請）
```

### 作り直しかた

`py run.py update` が下の手順をまとめて行う。1つずつ動かすなら:

```
cd src
py run.py daily            # Campusmateの一覧を取り直し、新しい科目の本文を取る
py lit.py                  # 文学部のシラバスを取り直す
py run.py rooms --refresh  # 各学部の時間割表PDFを取り直し、教室と事前申請を作る
py run.py site             # ページを組み立てる
py run.py deploy           # index.html と details-2026/ をこのリポジトリの直下に置く（push はしない）
```

DB・ビルド出力・時間割PDFはこのリポジトリの外（既定で `C:\Users\<ユーザー>\syllabus-db\`）に置く。
合わせて数十MBあり、OneDrive 配下に置くと作り直すたびに同期が走るため。場所は環境変数
`SYLLABUS_DB_PATH` / `SYLLABUS_EXPORT_DIR` / `SYLLABUS_PDF_DIR` で変えられる。
PDFは `run.py rooms` が取りに行くので手当ては要らない。取得先は `src/timetable_pdfs.py`
にまとめてあり、学部がファイル名を変えて404になったらそこを直す。
