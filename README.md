# 九大 授業さがし（2026年度）

九州大学のシラバスを、時間割のコマから探せるようにした1枚のWebページです。
`index.html` だけで動きます。サーバーもデータベースも要りません。

**公開URL**: https://tqnk00.github.io/kyudai-courses/

## できること

- 学部・科目区分・学年・キャンパス・開講期での絞り込み
- 科目名・教員名・キーワードでの検索（全角/半角と空白区切りのAND対応）
- 時間割のコマを押すと、そのコマの科目一覧
- 科目名を押すと、授業概要・授業計画・成績評価の内訳・公式シラバスへのリンク
- ★でお気に入り登録。お気に入りだけの時間割に切り替え可能
- 「お気に入りを時間割化する」で、自分の時間割ページへ（コマの追加・削除、単位数の合計、
  教室、シラバスへのリンク。時間割アプリのような画面）
- 絞り込んだ状態がURLに残るので、その条件のままリンクで共有できる
- 開いた詳細は、絞り込みを変えても開いたまま
- 詳細の「文字を大きく」で本文を拡大（PCの全画面向け。URLにも残る）
- 教室を表示（1,391件）。文学部はシラバスから、基幹教育は開講科目一覧（B表）から、
  ほかの学部は各学部が公開している時間割表から取得
- 基幹教育の**事前申請**（155件）を一覧のタグと詳細に表示。○はMoodleでの事前申請が必要、
  ●はCampusmate‑Jでの履修登録が申請を兼ねる。※は教員による抽選。2026年度入学者用と2025年度入学者用の
  どちらのB表に書かれた印かも示す
- 時間割表には載っているのにシラバスが無い科目（65件）を、ページ下部に一覧で掲載
- 「学部を色分け」で一覧の学部ごとに色を付ける（既定は色分けなし）
- 縦画面でも、1〜2件しかないコマは科目名まで表示
- スマホ表示対応。ダークモード対応

## データについて

- 出典: 九州大学シラバス（Campusmate）／文学部シラバス・時間割（文学部独自サイト）
- 教室・事前申請の出典: 基幹教育院の開講科目一覧（B表）、教育・法・経済・理・工・農の各学部が公開している時間割表（PDF）
- 収録: 2026年度の**学部科目 2,647件**（Campusmate 2,391件 + 文学部 256件）
- 対象の開講期: 後期・秋学期・冬学期・通年が中心です。**全開講期を網羅したものではありません**
- 取得日: 2026-09-14〜15／ページ生成日: ページ下部に表示

**取得時点のスナップショットです。** 開講の有無・教室・日程・成績評価は変更されることがあります。
履修登録の判断は必ず公式のシラバスで確認してください。各科目の詳細から公式ページへ移動できます。

科目名・成績評価・授業計画は自動抽出しているため、原文と食い違う場合があります。
とくに成績評価の割合は、出席条件など配点でない数値を除く処理を入れていますが、完全ではありません。

## 更新のしかた

生成側のコード（このリポジトリには含めていません）で再生成した `kyudai-courses-2026.html` を
`index.html` として置き換え、push すれば反映されます。

```bash
cp /path/to/kyudai-courses-2026.html index.html
git add index.html && git commit -m "データ更新" && git push
```

## 技術メモ

- 単一のHTMLファイル（6.3MB、gzipで約1.4MB）。データはページ内にJSONとして埋め込み
- 外部依存はGoogle Fontsのみ。読み込めない環境では代替フォントで表示
- お気に入りは `localStorage` に保存。端末のブラウザごとで、サーバーには送りません
